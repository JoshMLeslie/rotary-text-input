# rotary-text-input

A five-key-per-hand chord keyboard whose layer channel is mechanical: the key platter rolls ±45° about a rod aligned with the forearm, through seven detents at 15°. Fingers chord the character; forearm rotation selects the layer. Disjoint muscle groups, zero re-homing, ~6.7 bits per keystroke.

Status: concept — no hardware, no firmware, no key map yet.
